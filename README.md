# The Foul-Mouthed Oracle - home-screen launcher

A one-page site (GitHub Pages) that gives The Foul-Mouthed Oracle a crimson icon and the name "Foul Oracle" on a
phone or tablet home screen. Opened from the home screen it goes straight to the app at
https://foul-mouthed-oracle.streamlit.app/ (one line, `var APP_URL`, in index.html). The app is not embedded in a frame,
because Streamlit apps in frames go blank on iPhone Safari.

Publish: Settings > Pages > Deploy from a branch > main / (root).
